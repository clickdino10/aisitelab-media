# AI Site Lab Short toolkit

- `kit.py`: shared helpers (Kokoro voice with per-line timing, branded background, captions, phone frame, end card, render to MP4, contact sheet).
- `a/`: format "Client vs Designer chat" (reference script).
- `b/`: format "Roast this website" (reference script; bad.html / good.html; Comic Neue font, SIL OFL).

Copy to /root/funny before use: `mkdir -p /root/funny && cp -r tools/* /root/funny/`. Scripts expect Kokoro files at /root/tts.
